# Launcher Migration Map

Status: W7-A round 2; `finalize` and terminal meta finish are Python-owned.

Target doctrine: Python owns prepare/spawn/monitor/report/finalize. Bash stays as
a compatibility and operator-terminal wrapper until each responsibility has a
contract test and a Python receiving side.

## First Move

`finalize` moved first because it is file-shaped, has existing lifecycle and
artifact-truth tests, and is not coupled to vc_frame or terminal UI. The Python
source of truth is now `vibecrafted_core.spawn.finalize_artifacts`; shell
`spawn_finalize_artifacts` delegates to `python3 -m vibecrafted_core.spawn
finalize-artifacts ...` and then performs the existing control-plane sync.

## Second Move

`finish_meta` moved second because the map already marked it as the next
file-shaped closure responsibility after `finalize`. The Python source of truth
is now `vibecrafted_core.spawn.finish_meta`; shell `spawn_finish_meta` is a
compatibility delegator used by generated launchers and marbles paths. The
remaining monitor, execution, visible/headless launch, command-payload, and
report-hook responsibilities stay blocked by TTY, stream-capture, or
agent-specific behavior and were re-checked against current launcher code in
W7-A.

## Third Move

`write_meta` (initial meta writing) moved third because the map marked it as the final blocker for control-plane schema writing. The Python source of truth is now `vibecrafted_core.spawn.write_meta`; shell `spawn_write_meta` is a compatibility delegator that calls the Python writer and preserves control-plane sync. After this cut, both birth and death of a run's meta lifecycle speak Python.
